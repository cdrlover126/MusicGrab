# 乐取 MusicGrab v1.6.0 发布说明

发布日期：2026-10-26
平台：Windows x64（Windows 10 / 11）

## 1. 本版要点

- **智能路由**：新增 `auto` 模式，按目标域名自动决策——国内平台（抖音/快手/酷狗/B站/微博/网易云等）直连，境外站点（YouTube/TikTok/X 等）自动使用指定代理。中国平台的 CDN 全球部署，因此该规则对国内与境外用户同时成立。
- **代理错误可读化**：新增代理预检与专项报错，区分"代理未启动/端口不符/超时"与"平台风控"，避免用户被错误信息带偏。
- **详情日志页签**：处理期间不再禁用整个 `QTabWidget`，「详情日志」可实时查看、复制与搜索。
- **无控制台窗口**：GUI 模式下调用的 ffmpeg / ffprobe 不再闪现黑色终端窗口（`CREATE_NO_WINDOW`），命令行模式行为不变。

## 2. 完整变更

### 新增
- `douyin_mp3/proxy.py`：智能路由引擎（域名集合判定、直连可达性探测、错误信息翻译）
- `douyin_mp3/winconsole.py`：Windows GUI 模式下的子进程控制台窗口抑制
- 路由模式 `auto` / `direct` / `proxy` 三选一，默认 `auto`
- `packaging/make_screenshots.py`、`packaging/make_diagrams.py`：文档插图自动生成
- `packaging/make_release.py`：发布包自动打包与 SHA256 校验

### 修复
- 路由决策未作用于内置解析器（酷狗/快手曾硬编码代理）
- 代理不可用时被误报为"平台风控"并无效重试 3 次
- `requests` 静默继承系统代理导致"未配置却报代理错误"
- 音质下拉预设失效，输出恒为 32kbps
- 批量去重按整行文本比较，口令与裸链接无法去重
- 处理期间「详情日志」页签无法点击

### 变更
- 默认路由策略由"全局代理"改为"智能"
- 应用更名为「乐取 MusicGrab」，可执行文件为 `MusicGrab.exe`
- APP_ID：`com.cdrlover.musicgrab`

## 3. 运行环境

- 操作系统：Windows 10 (1809+) / Windows 11，x64
- 免安装、免 Python 环境；单文件 exe，双击运行
- 首次使用境外平台需在「输出设置 → 代理」填入本地代理地址（如 `http://127.0.0.1:7890`）
- 首次运行联网以检测代理可达性；本地视频转码可完全离线

## 6. 已知限制

- 平台付费/VIP 内容需登录，本程序不提供绕过
- 抖音风控为平台策略，偶发失败内置 3 次重试
- 内置 FFmpeg 缺少 `mpegps` 解复用器，**不支持 VOB 容器**
- WebM 仅支持 Vorbis/Opus 音频轨
- YouTube 部分视频需 PO Token，由 yt-dlp 侧限制
- MSIX 打包与签名需 Windows SDK，当前发布形式为 exe

## 7. 安全与隐私

- 不收集、不上传任何用户数据；无遥测、无统计上报
- 仅处理用户主动粘贴的公开链接与用户本地文件
- 网络请求仅指向目标平台与用户自行配置的代理
