# 乐取 MusicGrab v1.7.0 发布说明

发布日期：2026-10-28
平台：Windows x64（Windows 10 / 11）

## 1. 本版要点

**新增「组件自检与在线升级」机制。**

程序用 PyInstaller 打成单文件 exe，**yt-dlp 与 ffmpeg 都被冻结在 exe 内部**，上游更新
不会自动生效。而 yt-dlp 几乎每周发版，原因就是目标站点一改版它就得跟着修——这会让
用户手里的旧程序**静默失效**：昨天还能下的链接今天下不到了，用户既不知道原因，
也不可能自己升级一个绿色单文件 exe。

v1.7.0 起，程序会在启动时自检组件版本，发现新版本主动提示，并支持一键就地升级：

| 阶段 | 行为 |
|---|---|
| 启动自检 | 后台线程联网比对官方最新稳定版，不阻塞界面；检查失败静默降级 |
| 提示 | 窗口顶部黄色横幅，可「立即升级 / 忽略此版本」 |
| 升级 | 从 PyPI 官方仓库下载 wheel（国内自动切镜像），校验 SHA256 后解压安装 |
| 生效 | yt-dlp 走自定义 import finder 优先加载外置副本；ffmpeg 走路径优先级 + `IMAGEIO_FFMPEG_EXE`；**重启一次即生效** |

## 2. 完整变更

### 新增
- `douyin_mp3/updater.py`：组件自检与升级核心模块（不依赖 PySide6，可独立单测）
  - 版本比对（按数字元组，正确处理 `2026.10.26` vs `2026.08.19` 这类日期型版本）
  - 远端版本查询：官方 PyPI JSON API 优先，超时/失败自动切清华 / 阿里 / 腾讯 / 华为镜像
  - 流式下载 + SHA256 校验 + zip-slip 防护 + 原子替换（失败自动回滚）
  - `_ExternalPackageFinder`：让外置 yt-dlp 覆盖 PyInstaller 冻结模块
- GUI 顶部「组件更新」横幅（可关闭、可忽略此版本）
- GUI「输出设置 → 组件更新」：启动时检查开关 + 「立即检查」按钮
- CLI 子命令 `check-update`（支持 `--json` / `--upgrade`），便于脚本化与排障
- 覆盖层目录 `%LOCALAPPDATA%\MusicGrab\`：`yt_dlp/`、`ffmpeg/`、`state.json`
- `tests/test_updater.py`：29 个单元测试
- `packaging/check_upgrade_e2e.py`、`packaging/check_overlay_usable.py`：端到端验证脚本
- `packaging/probe_update_banner.py`：横幅与设置行的界面截图工具

### 变更
- 版本号 1.6.0 → **1.7.0**
- `find_ffmpeg()` 优先级调整为：用户指定路径 → **外置升级版** → 系统 PATH → 内置
- 覆盖层在程序启动早期自动生效（`douyin_mp3/__init__.py`）

### 修复
- **后台线程改为 daemon 线程**：原先批量转换与自检都跑在 `QThread` 上，窗口关闭时线程
  会被"运行中销毁"，Qt 直接 terminate 掉进程（用户看到的是程序崩溃）。改为
  daemon 线程 + Qt 信号投递，并补上 `closeEvent` 在关闭时请求停止当前任务。
- yt-dlp 版本号读取兼容 `version.py` / `_definitions.py` / `__init__.py` 三种位置
  （yt-dlp 的 `__init__.py` 根本不导出 `__version__`，只在 `version.py` 里）
- PyPI **发行名**是 `yt-dlp` 而 **wheel 文件名**用下划线 `yt_dlp`，匹配时做归一化
- 简单索引不是按版本号排序（`2026.10.26` 排在 `2026.8.19` 前面），必须按数字元组取最大值
- 简单索引含 dev/rc 预发布版本，按纯数字版本号过滤
- 解压时剥掉包前缀，避免产生 `yt_dlp/yt_dlp/` 双重嵌套

## 3. 运行环境

- 操作系统：Windows 10 (1809+) / Windows 11，x64
- 免安装、免 Python 环境；单文件 exe，双击运行
- 首次使用境外平台需在「输出设置 → 代理」填入本地代理地址（如 `http://127.0.0.1:7890`）
- 首次运行联网以检测代理可达性；本地视频转码可完全离线
- 组件自检需要访问 PyPI；不通时程序照常工作（只是不提示更新）

## 4. 文件校验

```
SHA256 (MusicGrab.exe):
3ee3d6134d83c5a66efa0884151d14df50a4be2bca4e07ef0a1c7e3d9aab9c6f

SHA256 (发布包 MusicGrab-v1.7.0-win-x64.zip):
见发布目录同级的 SHA256SUMS.txt
```

> 发布包自身的 SHA256 放在 zip **外面**的 `SHA256SUMS.txt` 里——因为把校验值写进
> zip 内部会形成自引用，哈希永远对不上。

## 6. 已知限制

- 平台付费/VIP 内容需登录，本程序不提供绕过
- 抖音风控为平台策略，偶发失败内置 3 次重试
- 内置 FFmpeg 缺少 `mpegps` 解复用器，**不支持 VOB 容器**
- WebM 仅支持 Vorbis/Opus 音频轨
- YouTube 部分视频需 PO Token，由 yt-dlp 侧限制
- yt-dlp 升级需**重启程序**后生效（当前会话已加载的模块无法热替换）
- 组件自检只覆盖 yt-dlp 与 ffmpeg，**不检查应用自身版本**
- MSIX 打包与签名需 Windows SDK，当前发布形式为 exe

## 7. 安全与隐私

- 不收集、不上传任何用户数据；无遥测、无统计上报
