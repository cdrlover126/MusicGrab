## 四、上传操作步骤

### 文章

1. 登录 CSDN → 右上角「创作」→ **写文章**
2. 标题粘贴上面的首选标题；正文编辑器切到 **Markdown 模式**，粘贴 `CSDN-技术博文.md` 全文
3. 图片：Markdown 中的 `../images/xx.png` **不会自动上传**，需要
   - 逐张在正文对应位置「上传图片」（CSDN 会转存到自己的 CDN），或
   - 用「Markdown 转 HTML」后以富文本粘贴，图片用外链
   - **建议顺序**：先在编辑器里插入 9 张图占位，再逐张替换
4. 分类、标签、关键词按上表填；勾选原创 + 首发
5. 封面图按「封面候选」上传
6. 发布前检查：文末「相关阅读」链接替换为真实地址；免责声明段落保留
7. 预览 → 发布

### 资源

1. 「创作」→ **上传资源** → 选择 zip 文件
   - `MusicGrab-v1.8.0-win-x64.zip`：**单文件版**（主资源，普通用户下这个）
   - `MusicGrab-v1.8.0-win-x64-folder.zip`：**目录版**（可选资源，启动快、组件在 exe 旁边、可整个文件夹拷贝）
2. 填标题、分类、标签、简介、详细说明
3. **下载方式选「免费直接下载」**（或 0 积分）
4. 上传 3 张截图作为资源展示图
5. 提交后把资源链接回填到文章的「资源下载」小节
6. 关联：在文章正文或「相关资源」里挂上该资源，资源与文章互相引流

> 两个包里的 `SHA256SUMS.txt` 给出各自的校验值；资源详情页里贴一下更稳妥。

## 五、发布前合规自检

- [ ] 文中保留「仅供个人学习、研究与非商业用途」免责声明段落
- [ ] 文末「免责声明」完整保留，未删改
- [ ] 资源设为**免费/自取**，不设置积分或售价
- [ ] 未在正文中宣传「绕过 VIP」「破解」「无限下载」等表述
- [ ] 未引导读者去抓取未授权的付费内容
- [ ] 资源详情页如实说明内置 FFmpeg 为 GPLv3 并给出源码获取方式
- [ ] 未使用他人 logo / 未授权的界面截图
- [ ] 正文图片均为自绘或自截图
- [ ] `相关阅读` 中的占位 GitHub 地址已替换

### 为什么建议免费

《最高人民法院关于审理网络著作权民事纠纷案件适用法律若干问题的解释（一）》第二十八条明确：**通过收取服务费、会员费或者广告费等方式营利的，收取的费用应当认定为「违法所得」**，而司法解释〔2025〕5 号第十三条把「为他人避开、破坏技术措施提供技术服务」且违法所得达标的行为纳入侵犯著作权罪追责范围。

本工具内置了针对具体平台的解析实现，落在抖音/5sing 用户协议的「禁止使用第三方工具、爬虫抓取、模拟下载」条款范围内。**免费 + 仅供学习研究 + 不设积分门槛 + 不接入广告**是把合规风险降到最低的组合。

> 详见博文第 9 节「一次认真的合规评估」。
