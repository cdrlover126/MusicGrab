# 隐私政策

**生效日期：2026-10-18**

乐取 MusicGrab（“本应用”）是一款本地运行的音频提取工具。

## 我们收集的信息
本应用**不收集、不上传、不统计**任何个人信息或使用数据。

## 数据处理方式
- 视频/音频文件仅在本机临时目录处理，转换完成后自动删除（可选保留）。
- MP3 文件仅写入你选择的输出目录。
- 应用会访问你主动粘贴的抖音公开分享链接以获取视频信息；不会访问你的抖音账号、私信或关注列表。

## 网络与第三方
- 仅请求抖音公开页面/公开播放地址。
- **组件版本自检**（v1.7.0 起）：启动时会向 PyPI 官方仓库（及国内镜像）请求组件版本信息，
  并在下载更新时校验 SHA256。该过程**不发送任何本地信息**（无链接、无 Cookie、无文件信息），
  只发出常规的 HTTP 请求头。可在「输出设置 → 组件更新」中关闭启动时自动检查。
- 不包含广告、追踪 SDK 或统计上报。

## 未成年人
本应用面向成年用户的一般用途。

## 联系方式
如对本政策有疑问，请通过项目仓库 Issues 联系维护者。
